Tokenisation converts a byte sequence into a sequence of integer identifiers drawn from a fixed vocabulary. Byte-pair encoding begins with a vocabulary of single bytes and repeatedly merges the most frequent adjacent pair until the target vocabulary size is reached. The resulting merge table is applied deterministically at inference time, so identical input strings always produce identical identifier sequences. Whitespace is usually attached to the following token rather than treated as a separator, which keeps the round trip from identifiers back to text exact.

Positional information enters the residual stream either through learned absolute embeddings or through a rotary transform applied to the query and key projections. Rotary embeddings rotate pairs of coordinates by an angle proportional to position, so the dot product between a query and a key depends on their separation rather than their absolute offsets. The base frequency controls how quickly the rotation cycles, and raising it extends the range over which distinct positions remain distinguishable.

Layer normalisation rescales a vector to unit variance before the learned gain is applied. Root-mean-square normalisation omits the mean subtraction, which removes one reduction over the hidden dimension and leaves the direction of the vector unchanged up to scale. Both variants are applied before the attention and feedforward blocks in most current architectures, with a final normalisation immediately preceding the unembedding matrix.

Attention computes a weighted sum over value vectors, where the weights come from a softmax over scaled query-key dot products. Grouped-query attention shares a single key and value head across several query heads, which reduces the size of the cache held during decoding without altering the number of distinct query projections. Sliding-window layers restrict each position to a fixed span of preceding positions, bounding the cache at the cost of direct long-range access in those layers.

The feedforward block expands the hidden dimension by a fixed multiple, applies a nonlinearity, and projects back. Gated variants split the expansion into two halves, pass one through the nonlinearity, and multiply the two elementwise before the projection. The expansion factor and the choice of gate account for the majority of the parameter count in a decoder-only stack.

Mixed precision arithmetic stores parameters and activations in a reduced format while accumulating reductions in a wider one. The reduced format halves memory traffic, which is the binding constraint on throughput for memory-bound operations such as decoding a single token at a time. Numerical differences between backends arise mainly from the order in which reductions are performed, since floating point addition is not associative.

Key-value caching stores the projected keys and values for every processed position so that generating each subsequent token requires attention against the cache rather than a full recomputation. The cache grows linearly in sequence length and in the number of key-value heads, and it typically dominates memory use during long generations. Eviction strategies discard entries by position or by an estimate of their contribution to future attention weights.

Sampling converts the final distribution over the vocabulary into a chosen identifier. Greedy selection takes the highest-probability entry. Temperature divides the logits before the softmax, flattening or sharpening the distribution. Nucleus sampling restricts the candidate set to the smallest group whose cumulative probability exceeds a threshold, and renormalises across that group before drawing.

Quantisation maps parameters onto a smaller set of representable values, storing a scale and sometimes an offset for each group of weights. Group size trades reconstruction error against metadata overhead. Weight-only schemes dequantise during the matrix multiply and leave activations in the wider format, which preserves accuracy on operations that are sensitive to activation range.

Batched inference groups several sequences so that a single matrix multiply serves all of them. Sequences of unequal length are padded to a common length and a mask prevents padded positions from contributing to the attention weights. Left padding keeps the final real token of every sequence at the same offset from the end, which matters whenever a computation reads a fixed offset from the end of the input.

Checkpoint files store parameters together with the metadata needed to reconstruct the module hierarchy. Sharded formats split the parameters across several files with an index mapping each parameter name to its shard. Memory mapping allows a shard to be read lazily, so only the pages actually touched are brought into resident memory.

Deterministic execution requires fixing every source of variation: the seed for any sampling, the reduction order in the backend, and the exact version of the kernels in use. Two runs that differ in none of these produce bitwise identical outputs. Two runs that differ in any of them may diverge slowly, with small differences amplified over successive layers.
